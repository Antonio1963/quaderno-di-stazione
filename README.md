# Quaderno di Stazione

Registro QSO da compilare, stampare ed esportare (PDF, Excel, CSV, ADIF, backup), dispensa di regolamentazione con audio, simulazione d'esame, schede di ripasso, mappe mentali e mappe concettuali.

- **Online:** https://antonio1963.github.io/quaderno-di-stazione/
- **Sul PC:** apri `index.html` con il browser (funziona anche senza Internet).

Il registro e i progressi restano salvati solo nel browser di chi usa la pagina: nessun dato viene inviato in rete. Ricordati di esportare ogni tanto il registro.
